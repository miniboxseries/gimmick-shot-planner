# Gimmick Shot Planner

เครื่องมือวางช็อตสำหรับงาน AI film / TVC — ไฟล์ Python 1 ไฟล์ HTML 1 ไฟล์ กับ `project.json` อีก 1 ไฟล์
ไม่ต้องลงอะไรเพิ่มเลย มันเปลี่ยนช็อตลิสต์ให้เป็น prompt ที่คุมโทนเดียวกันทั้งเรื่อง เก็บภาพที่เรนเดอร์ไว้กับช็อตของมัน
แล้วพิมพ์ออกมาเป็นสตอรี่บอร์ดส่งลูกค้าได้เลย

## ทำไมต้องมี

พอเจนงาน 40 ช็อต ปัญหาจริงไม่ใช่การเขียน prompt แต่คือการคุมภาพ 400 รูป prompt 40 อัน
กับหน้าตาสินค้าที่ล็อกไว้ ไม่ให้มันเพี้ยนออกจากกัน เครื่องมือนี้ทำแค่เรื่องนั้น:

- **ล็อกสไตล์ไว้ที่เดียว** — คำอธิบายสินค้า โทนหนัง คำที่ไม่เอา เขียนครั้งเดียว แล้วมันแปะให้ทุก prompt
  ช็อตที่ 39 เลยยังหน้าตาเหมือนช็อตที่ 1
- **prompt ถูกสร้างให้ ไม่ใช่ copy-paste** — เลือกขนาดภาพ มุมกล้อง การเคลื่อนกล้อง โลเคชั่น สถานะสินค้า
  จากปุ่มชิป แล้วมันประกอบ prompt ใหม่จากเทมเพลตของเราเอง
- **ปุ่มเดียวจบต่อช็อต** — กดคัดลอกแล้วมันต่อท้ายด้วย *Take 1…10* (เปลี่ยนเลนส์/ไฟทีละสเต็ป)
  การเจนซ้ำเลยเป็นระบบ ไม่ใช่สุ่มไปเรื่อย
- **ภาพที่เรนเดอร์อยู่กับช็อต** — โยน `flow_07.png` ลงโฟลเดอร์ช็อต การ์ดก็นับให้เอง
  เปิดดูเต็มจอแล้วกดดาวภาพเด็ด ภาพนั้นจะกลายเป็นรูปหน้าปกในสตอรี่บอร์ด
- **สตอรี่บอร์ด → PDF** — กดพิมพ์ แล้วเลือก Save as PDF ได้ของส่งลูกค้าเลย
- **ทุกอย่างเป็นไฟล์ธรรมดา** — `project.json` + โฟลเดอร์ละช็อต ไม่มีฐานข้อมูล ไม่มีแอคเคาต์ ไม่มีคลาวด์

## เริ่มใช้

ต้องมี Python 3.8 ขึ้นไป กับเบราว์เซอร์ แค่นั้น ไม่ต้อง pip install อะไรเลย

```bash
git clone https://github.com/miniboxseries/gimmick-shot-planner.git
cd gimmick-shot-planner
python3 shot_planner.py            # เปิด http://127.0.0.1:8765/ ให้เอง
```

บนแมคดับเบิลคลิก **Start Planner.command** ก็ได้ บนวินโดวส์ใช้ **start.bat**

ในรีโปมีโปรเจกต์เดโมติดมาให้ (สปอตกระติกกาแฟ) จะได้เห็นภาพว่าหน้าตาตอนใช้งานจริงเป็นยังไง
พอจะเริ่มเรื่องของตัวเอง ก็ลบของใน `shots/` ทิ้ง แล้วเขียน `project.json` ใหม่

> ให้เปิดที่ `http://127.0.0.1:8765/` นะ — ถ้าเปิดไฟล์ `planner.html` ตรงๆ แบบ `file://`
> จะได้โหมดดูอย่างเดียว แก้อะไรไม่ได้ (หน้าเว็บจะเด้งไปเปิดผ่านเซิร์ฟเวอร์ให้เองถ้ามันหาเจอ)

| **ช็อตทั้งหมด** | ช็อตทุกช็อตเป็นการ์ด: รูป คำอธิบาย จำนวนภาพที่เรนเดอร์แยกตามช่องทาง กดคัดลอก prompt ได้เลย |
| **สตอรี่บอร์ด** | เลย์เอาต์สำหรับพิมพ์ 3 ช่องต่อแถว กดพิมพ์แล้ว Save as PDF ส่งลูกค้า |

## prompt ประกอบขึ้นมายังไง

แต่ละ **channel** (เครื่องมือเจนภาพที่เราใช้) มีเทมเพลตของตัวเอง มีสำเร็จรูปให้ 2 แบบ:

- `"style": "full"` — prompt แบบย่อหน้า สำหรับ Flow / Veo / GPT Image / Nano Banana
- `"style": "tags"` — prompt แบบคั่นคอมม่า สำหรับ ComfyUI / SDXL / Krea

ทั้งสองแบบประกอบจากข้อมูลช็อตชุดเดียวกัน มันเลยตรงกันเสมอ ถ้าจะเขียนเองก็ใส่ `"template"`:

```json
{ "id": "mj", "label": "Midjourney", "prefix": "mj_", "target": 4,
  "template": "{action}, {loc_short}, {size} {angle}, {product_short} --ar 16:9 --style raw" }
```

ตัวแปรที่ใช้ในเทมเพลตได้:

| | |
|---|---|
| `{head}` `{tail}` `{tail_short}` | ข้อความสไตล์หัว/ท้ายที่ใช้ทุกช็อต |
| `{size}` `{angle}` `{move}` `{loc}` `{loc_short}` | กล้องกับโลเคชั่นที่เลือก (เป็นภาษาอังกฤษสำหรับ prompt) |
| `{product}` `{product_short}` `{state}` `{state_short}` | บล็อกล็อกสินค้ากับสถานะปัจจุบัน — ถ้าช็อตนั้นตั้งสถานะเป็น `na` จะว่างทั้งหมด |
| `{action}` `{desc}` `{cast}` `{sec}` `{folder}` | สิ่งที่เราพิมพ์ให้ช็อตนั้น |
| `{camera_line}` `{action_line}` `{location_line}` `{people_line}` | บรรทัดสำเร็จรูป ถ้าไม่มีข้อมูลมันจะหายไปทั้งบรรทัด |

ตัวแปรที่พิมพ์ผิดจะกลายเป็นค่าว่างแทนที่จะพัง และบรรทัดว่างจะถูกยุบให้ —
ช็อตที่ไม่มีสินค้าไม่มีคนก็เลยยังได้ prompt ที่สะอาด

## project.json

ไฟล์เดียวที่ต้องแก้ ทุกอย่างข้างล่างนี้ใส่หรือไม่ใส่ก็ได้ ยกเว้น `shots`

| คีย์ | คืออะไร |
|---|---|
| `name` | ชื่อที่โชว์บนหัวเว็บ |
| `lang` | `th` หรือ `en` — ภาษาของหน้าเว็บ |
| `port` | ค่าเริ่มต้น `8765` |
| `shots_dir` `sheets_dir` `script_file` | ชื่อโฟลเดอร์/ไฟล์ ถ้าอยากใช้ชื่ออื่น |
| `channels` | เครื่องมือเจนภาพที่ใช้: `id`, `label`, `prefix` (คำขึ้นต้นชื่อไฟล์เรนเดอร์), `target` (ตั้งเป้ากี่รูปต่อช็อต), `style` หรือ `template` |
| `prompt.head` / `.tail` / `.tail_short` | ข้อความสไตล์ที่แปะทุก prompt |
| `product` | `label`, `block` (ย่อหน้าล็อกดีไซน์สินค้า), `short` (เวอร์ชันสั้นสำหรับ prompt แบบแท็ก) |
| `options.sizes/angles/moves/locs/states` | ปุ่มชิปทั้งหมด แต่ละอันคือ `{id, label, en, short?}` — `label` คือสิ่งที่เห็นบนจอ ส่วน `en` คือสิ่งที่ลงไปใน prompt |
| `cast_presets` | ปุ่มตัวละครที่กดเลือกได้เร็วๆ |
| `takes` | บรรทัดที่ต่อท้ายตอนกดคัดลอก — Take 1…N |
| `shots` | ช็อตลิสต์ แต่ละช็อตคือ `{folder, sec, size, angle, move, loc, state, cast, desc, action?, picks?}` |

`states` คือวิธีล็อกสภาพสินค้าในภาพ (ปิดฝา / ไฟติด / ไม่มีสินค้าในช็อต)
ถ้าตั้งสถานะช็อตเป็น `na` บล็อกสินค้าจะไม่ถูกใส่ลง prompt ของช็อตนั้นเลย

## ไฟล์บนเครื่อง

```
project.json              หนังของเรา: ตัวเลือก บล็อกสไตล์ ช็อตลิสต์
script.txt                โชว์ในแท็บสคริปต์
sheets/                   ชีทตัวละคร / สินค้า / โลเคชั่น เลือกแนบเป็น ref ได้
shots/
  Shot_03_Reveal/
    prompt_flow.txt       สร้างให้อัตโนมัติ แก้เองได้
    prompt_comfy.txt
    ref/                  รูปอ้างอิงของช็อตนี้
    flow_01.png           ไฟล์ที่ขึ้นต้นด้วย prefix ของ channel = นับเป็นภาพที่เรนเดอร์แล้ว
    comfy_01.png
```

การนับภาพดูจากคำขึ้นต้นของชื่อไฟล์ — ตั้งชื่อเป็น `flow_01.png`, `comfy_07.png` แล้วการ์ดนับให้เอง
ไม่ต้อง import อะไรทั้งนั้น

## สั่งจากคอมมานด์ไลน์

```bash
python3 shot_planner.py            # เปิดใช้งาน (ค่าเริ่มต้น)
python3 shot_planner.py daemon     # เปิดแต่ไม่เด้งเบราว์เซอร์
python3 shot_planner.py build      # เขียนไฟล์ prompt ให้ทุกช็อตที่ยังไม่มี
python3 shot_planner.py build -f   # สร้าง prompt ใหม่ทับของเดิมทั้งหมดจาก project.json
python3 shot_planner.py scan       # อัปเดต planner_data.js (ไฟล์สำรองสำหรับโหมดอ่านอย่างเดียว)
```

`build` คือทางลัดตอนเริ่มโปรเจกต์: เขียนช็อตลิสต์ทั้งเรื่องลง `project.json` สั่งทีเดียว
แล้วทุกโฟลเดอร์ช็อตจะได้ prompt ครบ

## ข้อควรรู้

- **ไม่มีอะไรออกจากเครื่อง** เซิร์ฟเวอร์ผูกกับ `127.0.0.1` เท่านั้น
- **แก้แล้วบันทึกเอง** ลง `project.json` (เขียนแบบ atomic) หลังหยุดพิมพ์ประมาณ 1 วินาที
- **แก้ `project.json` ด้วยมือตอนเปิดหน้าเว็บอยู่ได้เลย** กด 🔄 แล้วมันโหลดใหม่ให้
- **เปิดอัตโนมัติตอนบูตบนแมค:** LaunchAgent ที่เรียก `/usr/bin/python3` จะอ่านไฟล์ใน `~/Desktop`,
  `~/Documents`, `~/Downloads` ไม่ได้ ถ้าไม่ได้เพิ่ม python ตัวนั้นเข้า
  *System Settings → Privacy & Security → Full Disk Access* — เลือกได้ว่าจะให้สิทธิ์
  ย้ายโปรเจกต์ไปที่อื่น หรือดับเบิลคลิก **Start Planner.command** เอาตอนจะใช้
